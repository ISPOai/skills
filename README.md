# ISPO Skills

Curated, project-installable skills for ISPO agents.

Each package lives under `skills/<id>/` with a root `SKILL.md`, its upstream
license, and an `UPSTREAM.md` attribution file. `catalog.json` is the
machine-readable registry consumed by ISPO.

The initial collection intentionally includes one standalone skill for each
supported category. Packages that require proprietary agent services or
forbid redistribution are not included.
